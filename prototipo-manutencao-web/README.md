# Protótipo de manutenção predial

Este protótipo é uma versão web responsiva baseada na planilha original.

## Como abrir

Abra `index.html` no navegador.

## O que esta versão já demonstra

- Dashboard com ativos, custos, vencidos e próximos serviços.
- Cadastro e edição de ativos.
- Campo de foto para ativo ou ocorrência, usando câmera/galeria no celular.
- Cronograma de eventos recorrentes.
- Visualização financeira por ano e simulação simples de aporte.

## Observações

- A planilha original não foi alterada.
- A cópia de trabalho `base_manutencao_predial_apartamento_trabalho.xlsx` recebeu a coluna `Foto`.
- As alterações feitas no protótipo ficam no armazenamento local do navegador.
- A próxima etapa natural é migrar esta interface para `Next.js + TypeScript`, com banco de dados e armazenamento de imagens.

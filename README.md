# Gestão de manutenção

Protótipo web para planejamento de manutenção predial, gestão de ativos,
cronograma de serviços, custos e provisionamento financeiro.

O aplicativo está em `prototipo-manutencao-web`.

O backend Supabase em desenvolvimento está em `supabase`. A primeira
migração cobre usuários, modelos de edificação, instâncias, localizações
hierárquicas e sistemas. Consulte `supabase/README.md` para aplicar a base e
criar os usuários de demonstração.
